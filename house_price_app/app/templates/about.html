Machine Learning Pipeline Architecture

The House Price Prediction platform processes real estate data through city-specific scikit-learn pipelines with median feature imputers, continuous StandardScaler transformations, categorical OneHotEncoders, and tuned Random Forest / Gradient Boosting regression estimators.

1. Data Ingestion
Clean NaN, IQR outlier capping
2. ColumnTransformer
StandardScaler + OneHotEncoder
3. Ensemble Model
Random Forest Regressors per City
4. Recommender
Cosine similarity & Value Scoring

RESTful API Endpoints

Integrate House Price Prediction valuations into external web and mobile clients.

GET /api/cities

Returns list of all configured metropolitan regions, coordinates, and availability.

GET /api/locations?city=Mumbai

Returns indexed localities for the specified city parameter.

POST /api/predict

Request JSON Payload example:

{
  "city": "Mumbai",
  "location": "Bandra",
  "total_sqft": 1200.0,
  "bath": 2,
  "BHK": 2
}

Response JSON example:

{
  "status": "success",
  "city": "Mumbai",
  "predicted_price_lakhs": 245.50,
  "formatted_price": "₹2.46 Crore",
  "confidence_interval": {
    "low": 233.22,
    "high": 257.78
  }
}
